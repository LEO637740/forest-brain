# Phase A public ground assets

Downloaded 2026-09-19 from Poly Haven's official files API and download host.
Two material sets only, six original 1K JPG maps, 5,300,860 bytes total.
No public plant models or HDRI were introduced.

|---|---|---|---|
| Forest Floor | https://polyhaven.com/a/forest_floor / eye-candy.xyz | CC0 | Thin litter / soil in existing production core, 2.1 m repeat; runtime muted moist/moss tint. Generic litter, not botanically certified rubber leaves. |
| Brown Mud | https://polyhaven.com/a/brown_mud / Rob Tuytel | CC0 | Compacted dirt road, road shoulder and damp drainage bed, 1.3 m repeat. Runtime road brightness, roughness and wear masks. |
